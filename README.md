# סוכן ה-SEO של Higanu

**מה זה?** זה "עובד" ממוחשב שדואג שגוגל ימצא את החנות שלך, higanu.co.il.

**מה הוא עושה כל שבוע (ביום ראשון בבוקר):**
1. **בודק** את כל המוצרים, הקטגוריות, הדפים והבלוג, ונותן לחנות ציון מ-0 עד 100.
2. **מתקן** דברים פשוטים ובטוחים: כותרות לגוגל, תיאורים קצרים מדי, תמונות בלי תיאור, ודפים ישנים שגוגל לא צריך לראות.
3. **כותב** מאמר אחד בעברית לבלוג ושומר אותו כטיוטה. את/ה קורא/ת, מוסיף/ה משהו אישי ומפרסם/ת.
4. **שולח לך דוח** במילים פשוטות: מה השתפר, מה הוא תיקן, ומה מחכה לך.

**מה הוא אף פעם לא עושה:**
- לא משנה מחירים, מלאי או כתובות של דפים.
- לא מוחק כלום.
- לא נוגע בעיצוב החי של האתר.
- לא מפרסם מאמרים בלי אישור שלך.

**איך מחזירים שינוי?** כל שינוי רשום בקובץ `seo/changelog.md` יחד עם מה שהיה לפני. אפשר לבקש מהסוכן: "תחזיר את השינוי של ..." והוא יחזיר.

**איפה הדוחות?** בתיקייה `seo/reports/`. הדוח הראשון: `seo/reports/2026-10-08.md`.

**רוצה לשנות משהו?**
- כדי שהסוכן יפרסם מאמרים לבד, כותבים לו: "מעכשיו תפרסם מאמרים לבד".
- להחליף את יום הדוח: "תעביר את הדוח ליום שני".
- כדי להריץ בדיקה עכשיו, כותבים בשיחה: "תריץ בדיקת SEO".
